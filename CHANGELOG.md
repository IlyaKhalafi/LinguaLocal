# Changelog

## 2.0.0

LinguaLocal runs as one Next.js service on the school network. Shared curriculum is managed through server files and command-line tools. Students use the hub without accounts.

- Optional private voice practice with playback, download, bounded device storage, and failed-save recovery.
- Selected offline audio, video, captions, and PDFs with explicit refresh controls
- Optional installation and bounded offline page storage
- Optional student summaries, translated print sheets and local classroom summaries
- Responsive library, dictionary, lessons, and four vocabulary practice modes
- English, Persian, Arabic, and Turkish interfaces with mirrored layouts
- Local audio and video, captions, timed transcripts, passage repetition, and dictation
- Saved words, spaced review, private progress, daily goals, and portable backups
- Classroom assignment links with private checklists and optional due dates
- Private study decks, word membership, tags, and optional adaptive review ratings
- Private notes beside words and lessons with protection for unfinished drafts
- Light and dark appearance, larger text, readable fonts, spacing, contrast, and quiet mode
- Six original book shells, 16 lessons, 150 words, and example curriculum packs
- Vocabulary spreadsheet import and export, printable worksheets, and answer keys
- Content validation, media diagnostics, subtitle conversion, and server snapshots
- Docker deployment, standalone archives, and local network QR codes

The previous Python implementation is preserved in [LinguaLocal-Before](https://github.com/IlyaKhalafi/LinguaLocal-Before).
