# Classroom expansion

The next release expands student practice, classroom materials, and local deployment. Each feature has a concrete classroom purpose. The hub stays usable without accounts or cloud services.

## Learning

- [ ] Installable app and cached pages for supported secure browser contexts
- [ ] Selected book media saved for offline playback
- [x] Timed transcripts with dictionary lookup
- [ ] Shadowing and dictation with word-level feedback
- [ ] Private voice recordings saved on the student device
- [ ] Spelling, listening, and gap-fill practice
- [ ] Named study decks and tags
- [ ] Review ratings, ease, lapses, and difficult-card practice
- [ ] Personal notes on words and lessons

## Classroom materials

- [ ] Assignment links with local checklists and optional due dates
- [ ] Printable vocabulary and lesson worksheets with separate answer keys
- [ ] Self-reported progress summaries and classroom roll-ups
- [ ] Vocabulary spreadsheet import and deck export
- [x] Subtitle conversion and timing diagnostics
- [ ] Server content snapshots and restore tools

## Everyday use

- [ ] Keyboard and accessibility coverage for every new workflow
- [x] Reading size, spacing, bundled reading font, and contrast
- [x] Quiet mode with reduced decoration and motion
- [ ] Dark appearance
- [x] English, Persian, Arabic, and Turkish interfaces with right-to-left support

## Owning the hub

- [x] Local address discovery and join QR codes
- [ ] Server configuration archives and storage diagnostics
- [x] Content diagnostics for missing media and unused files
- [ ] At least 150 original words, 10 new lessons, a pack gallery, and validation tools
- [ ] Contributor templates, changelog, and release packaging

Offline browser storage and microphone recording depend on browser capabilities. HTTPS on the school network enables service workers and microphone access. Plain HTTP continues to support the local learning hub. Personal reports contain the information students choose to share and do not verify identity.

Shared curriculum is managed on the server. Browser tools do not edit the school’s collection. Student pages use concise labels and show instructions only when needed.
